# Prisme branding (0.2.34)

Theme-aware layered SVG app logos and open navigation symbols. The runtime uses existing accent/indigo colors and preserves tab labels, click handlers and account preferences. Favicon cache key: prisme-1. Fresh installations and upgrades include the same static files. No media, authentication, VPN or storage behavior changes.

Canonical sources live in MediaHub frontend/src/brand-marks.json and nav-marks.json. Sync uses frontend/scripts/sync-brand-icons.mjs --workspace. FjordHub is unchanged.
